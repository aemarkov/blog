# Blog

This is my personal blog. It's about the technical stuff I did' or I tried to do, things I learned or just a random stuff I liked and want to share. 

## Under the hood

It's built with [Zola](https://www.getzola.org/), a static site generator written in Rust, [Tera](https://github.com/Keats/tera) templates and SASS. 

How to built:
1. Install Zola (obviously)
2. Build
   ```bash
   zola build
   # Or serve for development
   zola serve
   ```
3. That's it.
